# Personal Portfolio Website

A responsive personal portfolio website designed to showcase my professional background, technical skills, development projects, internship experience, and academic research.

## Project Overview

This portfolio serves as my personal professional website, providing an overview of my journey as a Computer Science graduate and Frontend Developer. It features a clean interface, interactive elements, and responsive layouts to present my work and technical experience.

## Key Features

- **Personal Introduction:** Professional overview and background.
- **Skills Showcase:** Displays programming languages, frontend technologies, and development tools.
- **Experience Section:** Highlights my Frontend Development Internship at Elevvo Pathways.
- **Projects Showcase:** Dynamically displays projects with category-based filtering and GitHub repository links.
- **Research Publication:** Features my Rice MultiNet research paper published through IEEE.
- **Dark/Light Mode:** Allows visitors to switch between visual themes with saved preferences.
- **Responsive Navigation:** Includes a mobile-friendly navigation menu.
- **Interactive Animations:** Includes typing effects, scroll-based reveal animations, and smooth navigation.
- **Contact Section:** Provides email contact and a form with client-side validation.
- **Downloadable CV:** Allows visitors to access my resume.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Adeeba333/portfolio_website.git
```

2. Navigate to the project directory:

```bash
cd portfolio_website
```

3. Open `index.html` in your browser or use the VS Code Live Server extension.
